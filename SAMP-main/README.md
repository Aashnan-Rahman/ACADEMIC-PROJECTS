# SAMP

SAMP (Student Academic Management Project) is a C++ console program for keeping student, course, teacher, attendance, and academic records together. It began as an object-oriented programming project focused on modelling a small academic administration system.

## Built with

- C++
- Object-oriented classes for academic records
- Local console input and output

## Run

Build `SAMP_v1.cpp` with a C++ compiler:

```powershell
g++ -std=c++17 SAMP_v1.cpp -o samp.exe
.\samp.exe
```

`SAMP V-1.0.0` is the previously compiled Windows executable included with the project.
