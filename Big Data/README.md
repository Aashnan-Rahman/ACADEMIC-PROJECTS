# Girvan–Newman Community Detection

This notebook explores community detection in an undirected graph. It works through breadth-first search, edge betweenness, iterative edge removal, and visualisation before comparing the result with NetworkX's Girvan–Newman implementation.

## Built with

- Python and Jupyter Notebook
- NetworkX
- pandas and NumPy
- Matplotlib

Open `Girvan_Newman_Assignment_(Aashnan_231041006).ipynb` in Jupyter or Google Colab and run the cells in order. The notebook includes the explanation, implementation, and visual output in one place.
