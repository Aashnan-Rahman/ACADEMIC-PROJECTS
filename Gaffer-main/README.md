# Gaffer FC

Gaffer FC is a browser-based football club manager. Different club roles have their own workspace, while managers can select a squad, choose a formation, place the starting XI on the pitch, and organise the bench.

**Live site:** [gaffer-silk.vercel.app/Gaffer-main](https://gaffer-silk.vercel.app/Gaffer-main/)

## Built with

- HTML, CSS, and vanilla JavaScript
- Browser localStorage for local play
- Vercel Functions and Vercel Blob for shared club data

The active web project is inside [`Gaffer-main`](./Gaffer-main/). Its README contains the demo accounts and deployment instructions.
