Field notes

  • Alpha improves recovery as it rises, but stronger values can leave more visible distortion.
  • DWT level trades resolution for robustness: level 1 has four times the bit capacity of level 2, while deeper levels may better survive attacks.
  • Padding uses reflected edge pixels and is removed from the downloaded result.
  • BER / NC measure the extracted watermark itself: BER 0 and NC 1 indicate perfect recovery.
