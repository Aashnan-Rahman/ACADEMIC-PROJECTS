# Mini-Genie

Mini-Genie is a collection of machine-learning experiments for recognising emotion from faces and speech. The notebooks cover dataset preparation, model training, evaluation, and comparisons with existing emotion-recognition libraries.

## Built with

- Python and Jupyter/Google Colab
- TensorFlow and Keras
- OpenCV
- scikit-learn, pandas, and NumPy

The main training notebooks are under `Colab_Files`; supporting speech-emotion and comparison work is under `Related Files`. The project report and presentation provide the quickest overview of the approach and results.
