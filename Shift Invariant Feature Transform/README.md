# Scale-Invariant Feature Transform

This project studies how SIFT finds and matches useful points across images even when scale or orientation changes. One notebook builds the pipeline step by step; the other provides a shorter comparison using OpenCV's implementation.

## Built with

- Python and Jupyter Notebook
- NumPy
- OpenCV
- Matplotlib

Start with `231041006_SIFT_Scratch.ipynb` for the from-scratch implementation. Use `231041006_SIFT_library.ipynb` for the OpenCV version and feature-matching example.
